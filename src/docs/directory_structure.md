# Структура каталогов проекта 3DViewer v2.0

Ниже приведено подробное описание структуры директорий и файлов внутри каталога `src/`.

```
src/
├── Makefile                          # Основной Makefile с целями: all, install, uninstall, clean, dvi, dist, tests
├── CMakeLists                        # Файл для сборки основной цели проекта (install) при помощи CMake. Вызывается из Makefile
├── Doxyfile                          # Конфигурация Doxygen для генерации документации
├── docs/                             # Исходники документации и результаты генерации
│   └── html/                         # Сгенерированная HTML-документация Doxygen
├── engine/                           # Модуль Model (бизнес-логика)
│   ├── model_engine.h                # Объявление класса s21::ModelEngine
│   ├── model_engine.cc               # Реализация класса s21::ModelEngine
│   └── model_data.h                  # Структуры Vertex, Edge, ModelData
├── utils/                            # Вспомогательные утилиты
│   ├── obj_parser.h                  # Объявление ObjParser
│   └── obj_parser.cc                 # Разбор файлов .obj
├── controller/                       # Модуль Controller
│   ├── controller.h                  # Объявление Controller
│   └── controller.cc                 # Обработка пользовательских команд и связь UI ↔ Engine
├── ui/                               # GUI (Qt)
│   ├── main_window.h                 # Описание главного окна
│   ├── main_window.cc                # Реализация главного окна и сигналов/слотов
│   ├── render_widget.h               # Компонент для визуализации модели
│   ├── render_widget.cc              # Реализация виджета для OpenGL/Canvas
│   ├── settings_dialog.h             # Описание окна настроек
│   ├── settings_dialog.cc            # Реализация окна настроек
    ├── shader.h                      # Объявления класса шейдеров
    └── shader.cc                     # Реализация класса шейдера
├── assets/                           # Ресурсы (иконки, шейдеры и пр.)
│   └── shaders/                      # GLSL-шейдеры
├── tests/                            # Unit-тесты (Google Test)
    ├── test_assets/                  # Тестовые данные
    ├── test_parser.cc                # Тесты парсера
    └── test_transformations.cc       # Тесты движка
├── main.cc                           # Точка входа в программу
│ 
└── dist/                             # Папка для готовых пакетов и архивов
```

## Пояснения к папкам и файлам

* **Makefile**: Управляет процессом сборки, установки, очистки, генерации документации и запуском тестов.
* **Doxyfile**: Конфигурация для генерации HTML документации через Doxygen.
* **docs/**: Содержит Markdown-исходники и сгенерированную HTML-документацию.
* **engine/**: Содержит код загрузки моделей, хранения и выполнения аффинных преобразований. Реализован принцип Facade.
* **utils/**: Подмодули для разбора OBJ-файлов
* **controller/**: Связующее звено между UI и бизнес-логикой — тонкий слой, реализующий команды пользователя.
* **ui/**: Компоненты пользовательского интерфейса (Qt), включая главное окно и виджет отрисовки.
* **assets/**: Графические ресурсы (иконки) и, при использовании OpenGL, шейдеры.
* **tests/**: Юнит-тесты, покрывающие загрузку моделей, аффинные преобразования.
* **dist/**: Место для итоговых собираемых архивов (\*.tar.gz, \*.zip) и пакетов.
